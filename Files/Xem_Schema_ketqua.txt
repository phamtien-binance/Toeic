===== 3. QUAN HỆ KHOÁ NGOẠI =====
RtAttemptAnswers AttemptId -> RtAttempts Id CASCADE (xoá theo) FK_RtAttemptAnswers_RtAttempts_AttemptId
RtAttempts ExamId -> RtExams Id NO ACTION (ch?n xoá) FK_RtAttempts_RtExams_ExamId
RtPassages ExamId -> RtExams Id NO ACTION (ch?n xoá) FK_RtPassages_RtExams_ExamId
RtQuestions ExamId -> RtExams Id NO ACTION (ch?n xoá) FK_RtQuestions_RtExams_ExamId
RtPassageDocuments PassageId -> RtPassages Id CASCADE (xoá theo) FK_RtPassageDocuments_RtPassages_PassageId
RtQuestions PassageId -> RtPassages Id NO ACTION (ch?n xoá) FK_RtQuestions_RtPassages_PassageId
RtAttemptAnswers QuestionId -> RtQuestions Id CASCADE (xoá theo) FK_RtAttemptAnswers_RtQuestions_QuestionId
RtQuestionOptions QuestionId -> RtQuestions Id CASCADE (xoá theo) FK_RtQuestionOptions_RtQuestions_QuestionId
===== 4. SƠ ĐỒ DẠNG CÂY =====
■ RtExams
     ⤷ RtAttempts  (ExamId, no action)
          ⤷ RtAttemptAnswers  (AttemptId, cascade)
     ⤷ RtPassages  (ExamId, no action)
          ⤷ RtPassageDocuments  (PassageId, cascade)
          ⤷ RtQuestions  (PassageId, no action)
               ⤷ RtAttemptAnswers  (QuestionId, cascade)
               ⤷ RtQuestionOptions  (QuestionId, cascade)
     ⤷ RtQuestions  (ExamId, no action)
          ⤷ RtAttemptAnswers  (QuestionId, cascade)
          ⤷ RtQuestionOptions  (QuestionId, cascade)
